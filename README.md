# SEIF Portfolio - Three Parallel Universes

A stunning, premium portfolio with three unique personas representing different creative dimensions.

## 🌌 Three Universes

### ⚡ Software Engineer
- Hacker lab aesthetic
- Neon green (#00ff88)
- Terminal vibes & grid overlay
- Crosshair cursor
- JetBrains Mono font

### 🌊 Photographer  
- Cinematic ocean theme
- Cyan/teal (#06b6d4)
- Deep ocean gradients
- Circular film cursor
- Cormorant Garamond font

### 🎬 Digital Creator
- Bold social energy
- Purple/pink gradients (#a855f7)
- Floating orbs
- Glowing cursor
- Space Grotesk font

## ✨ Premium Features

- 🎯 Magnetic buttons
- 🃏 3D tilt cards
- ✨ Custom cursors per persona
- 🌊 Smooth transitions
- 📊 Animated stat counters
- 🔦 Mouse spotlight effect
- 📱 Fully responsive

## 🚀 Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

## 📁 Structure

```
src/
└── app/
    ├── globals.css
    ├── layout.tsx
    └── page.tsx
```

## 🎨 Customization

Edit the `personas` object in `page.tsx` to update:
- Colors & themes
- Skills & levels
- Projects/Gallery
- Social links
- Timeline events
